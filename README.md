## Getting started

To get started with Mitch-Wiki, please refer to the repository's documentation (WIP) or check the [development guide](https://github.com/home/mitch-wiki).

## Features

- Real-time collaboration
- Diagrams (Draw.io, Excalidraw and Mermaid)
- Spaces
- Permissions management
- Groups
- Comments
- Page history
- Search
- File attachments
- Embeds (Airtable, Loom, Miro and more)
- Translations (10+ languages)
